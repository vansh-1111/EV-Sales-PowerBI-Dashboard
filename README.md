# EV Sales & Profit Analysis Dashboard

This is a Power BI project based on Electric Vehicle sales data.

I created this dashboard to understand how EV sales are performing across different models, manufacturers and regions. It also shows revenue, profit and other important sales metrics in one place.

## What this dashboard shows

- Total Revenue
- Total Orders
- Total EV Sold
- Total Profit
- Average Order Value
- Profit Margin
- Monthly Revenue Trend
- Sales by EV Model
- Revenue by Manufacturer
- Sales by Vehicle Type
- Sales by Region
- Profit by Region

## Tools Used

- Power BI
- Power Query
- DAX

## What I worked on

I cleaned and prepared the data in Power Query and then created measures using DAX. After that, I built the dashboard with different charts, KPI cards and filters.

The dashboard also has filters for Year, State and Region so the data can be explored interactively.

## Project File

`EV_Sales_Profit_Analysis.pbix`

## About the Project

This project was created as part of my learning and practice in Power BI and Data Analytics.

I focused mainly on understanding how raw sales data can be cleaned, analyzed and converted into a useful business dashboard.
